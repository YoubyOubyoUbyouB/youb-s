# 공유 그림판

여러 명이 동시에 접속해서 하나의 캔버스에 함께 그리고, 채팅으로 대화하는 웹 그림판입니다.
외부 패키지 설치 없이 Node.js만 있으면 바로 실행됩니다.

## 실행

```bash
node "C:\Users\ksyou\OneDrive\바탕 화면\로드엽\shared-paint\server.js"
```

실행하면 콘솔에 접속 주소와 **접속 암호**가 표시됩니다.

```
  내 PC        : http://localhost:3000
  같은 네트워크 : http://10.20.0.106:3000
  접속 암호     : 903351   ← 이 암호를 함께 전달하세요
```

## 접속 암호

`ROOM_PASSWORD` 환경변수로 정합니다.

| 설정 | 동작 |
|---|---|
| 지정 안 함 | 6자리 숫자를 자동 생성해 콘솔에 표시 (서버를 다시 켜면 바뀜) |
| `ROOM_PASSWORD="원하는암호"` | 그 값이 접속 암호가 됨 |
| `ROOM_PASSWORD="off"` | 암호 없이 개방 — **사내망 전용으로만** |

암호를 고정해서 실행하려면 (PowerShell):

```bash
$env:ROOM_PASSWORD="tripto2026"; node "C:\Users\ksyou\OneDrive\바탕 화면\로드엽\shared-paint\server.js"
```

포트를 바꾸려면 `$env:PORT=8080` 을 같은 방식으로 지정하면 됩니다.
종료는 실행 중인 창에서 `Ctrl+C`.

암호를 한 번 입력하면 12시간 동안 유지되고, 서버를 다시 켜면 모두 다시 입력해야 합니다.
암호를 10분에 10번 틀리면 해당 IP는 잠시 차단됩니다.

## 기능

| 기능 | 설명 |
|---|---|
| 펜 | 색상 8종 팔레트 + 직접 색 선택, 굵기 1~60 (슬라이더 또는 숫자 직접 입력) |
| 기본 도형 | 직선·네모·동그라미·세모·화살표·별을 드래그로 생성. 색상·굵기·실행취소·칸 제한 지원 |
| 붓 크기 표시 | 마우스를 따라다니는 원으로 현재 붓 굵기를 미리 보여줌 (지우개는 점선) |
| 지우개 | 굵기 조절 가능, 지운 것도 모두에게 실시간 반영 |
| 실행취소 | `↶ 실행취소` 버튼 또는 `Ctrl+Z`. **내가 그린 획만** 최신 순으로 취소되고, 남의 그림은 건드리지 않음 |
| 칸 나누기 | `⊞ 칸 나누기` — 참여자 수에 맞춰 캔버스를 격자로 나누고 각자 자기 칸에만 그리게 함. 누가 켜든 **모두에게 동시에 적용**됨 |
| 내 칸 지우기 | 칸 나누기 중일 때만 나타남. **내 칸 안에 그려진 것만** 지우고 다른 칸은 건드리지 않음 |
| 전체 지우기 | 확인창을 거쳐 모두의 캔버스를 초기화 (되돌릴 수 없음) |
| 참여자 표시 | 상단에 접속자 이름과 고유 색상 표시 |
| 커서 공유 | 다른 사람 마우스 위치가 이름표와 함께 실시간 표시 |
| 채팅 | 우측 패널, Enter 전송 / Shift+Enter 줄바꿈 |
| @지목 | 채팅에서 `@` 를 치면 참여자 목록이 뜨고, 지목된 사람 화면에서 그 메시지가 강조됨 (`@전체` 는 전원) |
| 사진·캡처 전송 | 채팅에 이미지 첨부, 붙여넣기(Ctrl+V), 그림판 화면 캡처, 화면 캡처 |
| 이름 변경 | 상단 입력칸에서 변경, 브라우저에 저장되어 다음에도 유지 |
| 빙고 | 상단 `🎲 빙고`로 전환. 4×4 / 5×5 판, 목표 줄 수, 차례 제한시간, 순서 변경 (아래 참고) |
| 라이어 게임 | 상단 `🕵 라이어`로 전환. 3명 이상, 주제 7종, 일반 / 바보 라이어 두 모드 (아래 참고) |
| 레이싱 | 상단 `🏎 레이싱`으로 전환. 방향키 조작, 1~5바퀴, 실시간 순위·랩타임 (아래 참고) |
| 활쏘기 | 상단 `🏹 활쏘기`로 전환. 드래그로 조준, 바람·중력 반영, 10점 만점 과녁 (아래 참고) |
| 물풍선 | 상단 `💧 물풍선`으로 전환. 물풍선으로 상대를 물방울에 가두는 최대 8명 대전 (아래 참고) |
| 나중에 입장 | 그때까지 그려진 그림과 채팅 기록을 그대로 받아 봄 |
| 자동 재연결 | 연결이 끊기면 1.5초마다 재접속 시도 |

캔버스는 1600×900 기준으로 동작하며, 화면 크기가 달라도 모두 같은 그림을 봅니다.

### 칸 나누기 규칙

접속 순서대로 왼쪽 위부터 칸이 배정됩니다.

| 인원 | 격자 |
|---|---|
| 2명 | 좌우 2칸 |
| 3~4명 | 2×2 |
| 5~6명 | 3×2 |
| 7~9명 | 3×3 |

- 칸 경계를 넘어가면 선이 경계에서 멈춥니다 (칸 밖으로는 그려지지 않습니다)
- 사람이 들어오거나 나가면 칸이 다시 배정됩니다. **이미 그려둔 그림은 그 자리에 남습니다**
- 칸을 끄면 다시 캔버스 전체에 자유롭게 그릴 수 있습니다
- 툴바에 `내 칸 지우기` 가 나타납니다. **내 칸 안의 획만** 지우므로 남의 칸은 그대로 남습니다

### 빙고 규칙

상단 `🎲 빙고` 버튼으로 전환합니다. 그림판 내용은 그대로 남아 있어 언제든 오갈 수 있습니다.

1. 판 크기(**4×4** 또는 **5×5**), 목표 줄 수, **차례 제한시간**을 고르고 `게임 시작`
2. 참여자마다 **서로 다르게 섞인 판**을 받습니다 (4×4는 1~16, 5×5는 1~25)
3. 접속 순서대로 돌아가며 자기 차례에 숫자를 하나 부릅니다
4. 부른 숫자는 **모두의 판에서 자동으로 체크**됩니다
5. 가로·세로·대각선으로 목표 줄 수를 먼저 채우면 승리 — 동시 달성이면 공동 우승

- 목표 줄 수는 판 크기에 맞춰 자동 조정됩니다 (4×4는 최대 10줄, 5×5는 최대 12줄)
- **시작할 때마다 순서가 무작위로 섞입니다** (원하면 아래 순서 변경으로 다시 조정)
- 누가 시작하면 **모두 자동으로 빙고 화면으로 전환**되고, 채팅에 진행 상황이 남습니다
- 게임 중에 들어온 사람도 판을 받아 순번 끝에 합류합니다
- 차례인 사람이 나가면 자동으로 다음 사람에게 넘어갑니다
- 자기 차례가 아니거나 게임이 끝난 뒤의 입력은 서버가 받지 않습니다

#### 차례 제한시간

- 기본 **10초** (제한 없음 / 10 / 15 / 20 / 30초 중 선택)
- 화면에 남은 시간이 표시되고, 3초 미만이면 빨갛게 바뀝니다
- 시간이 지나면 그 사람 판에서 **아직 안 나온 숫자를 무작위로 자동 선택**하고 다음 차례로 넘어갑니다
  (채팅에 `(시간 초과 — 자동 선택)` 으로 남습니다)
- 판정은 서버가 하므로 브라우저를 닫아두거나 자리를 비워도 게임이 멈추지 않습니다

#### 순서 변경

- 판 아래 `순서` 줄에서 각 사람의 `▲` `▼` 로 앞뒤로 옮기거나, `🔀 순서 섞기` 로 무작위 재배열
- **누구나** 바꿀 수 있고, 바꿔도 **지금 차례인 사람은 그대로 유지**됩니다

### 활쏘기 규칙

상단 `🏹 활쏘기` 버튼으로 전환합니다. **턴제**라서 인터넷 지연이 결과에 영향을 주지 않습니다.

1. 설정을 고르고 `게임 시작` — 시작할 때 순서가 무작위로 정해집니다
2. 자기 차례에 **드래그했다 놓으면** 화살이 날아갑니다
   - 당긴 **위아래 방향**이 각도, 당긴 **거리**가 힘 (최대 240px)
   - **앞으로 당기든 뒤로 당기든 화살은 항상 과녁 쪽으로** 날아갑니다
   - 드래그하는 동안 **굵은 예상 궤적**과 화살촉, 힘 게이지가 보입니다
3. 화살이 날아가는 모습은 **모두에게 실시간으로** 보입니다
4. 정해진 발수를 모두 쏘면 합계 점수로 순위가 정해집니다

**설정**

| 항목 | 선택지 |
|---|---|
| 발수 | 1발 / 3발 / 5발 |
| 거리 | 가까움(820) / 보통(1120) / 멂(1400) |
| 바람 | 없음 / 약함 / 강함 — **매 차례마다 무작위로 바뀝니다** |
| 과녁 | 고정 / 움직임 (위아래로 ±150px, 4초 주기) |
| 제한시간 | 제한 없음 / 15 / 20 / 30초 |

**점수** — 과녁 중심에서 벗어난 거리로 매깁니다.

| 벗어난 거리 | 점수 |
|---|---|
| 반지름의 20% 이내 | 10점 |
| 40% 이내 | 8점 |
| 60% 이내 | 6점 |
| 80% 이내 | 4점 |
| 과녁 안 | 2점 |
| 빗나감 | 0점 |

- 제한시간이 지나면 **자동으로 대충 발사**되고 다음 차례로 넘어갑니다
- 움직이는 과녁은 **화살이 도착한 순간의 높이**로 판정합니다
- 도중 입장한 사람은 관전만 하고 다음 판부터 참여합니다

**지연·부정행위 대응** — 궤적 계산과 점수 판정은 모두 서버가 합니다. 브라우저에는
조준 미리보기만 있고, 클라이언트가 보내는 값은 각도와 힘뿐이며 서버가 범위를 다시 제한합니다.
턴제라 레이싱과 달리 지연 보정이 필요 없습니다.

> 물리 상수(`AR`)와 과녁 좌표는 **서버에만** 있고 클라이언트로 내려보냅니다.
> 난이도를 바꾸려면 `server.js` 의 `AR` 만 고치면 됩니다.

### 물풍선 규칙

상단 `💧 물풍선` 버튼으로 전환합니다. **최대 8명**이 동시에 뛰어다니는 실시간 대전입니다.

**조작**

| 키 | 동작 |
|---|---|
| `←` `→` `↑` `↓` 방향키 | 이동 |
| `스페이스바` | 그 자리에 물풍선 놓기 |

> 물풍선은 **방향키만** 씁니다. `W` `A` `S` `D` 는 일부러 빼 두었습니다 —
> 채팅을 치다가 캐릭터가 멋대로 움직이는 일이 없도록 하기 위해서입니다.

**흐름**

1. 시작 옵션(시작 풍선 수·물줄기 길이)을 고르고 `게임 시작`
2. 3초 카운트다운 뒤 시작 — 각자 맵 가장자리에서 출발합니다
3. 물풍선은 놓고 **3초 뒤** 십자 모양으로 물줄기가 뻗습니다
4. 물줄기에 닿으면 **물방울에 갇혀** 그 자리에서 움직일 수 없게 됩니다
5. 갇힌 뒤 **6.5초** 안에 누군가의 물줄기가 다시 닿으면 **풀려납니다**
   (내 물줄기든 남의 물줄기든 상관없습니다 — 적을 실수로 구해 줄 수도 있습니다)
6. 못 풀려나면 물방울이 터져 **탈락**
7. **마지막까지 남은 한 명이 우승** · 3분이 지나면 무승부로 끝납니다

**맵**

- 21 × 12 칸. 회색 기둥은 못 부수고, 나무 상자는 물줄기로 부술 수 있습니다
- 출발 자리 둘레는 상자가 비워져 있어 갇힌 채로 시작하지 않습니다
- 판을 열 때마다 상자 배치가 새로 만들어집니다

**아이템** — 상자를 부수면 일정 확률로 나옵니다.

| 아이템 | 효과 | 최대 |
|---|---|---|
| 💧 | 물줄기가 한 칸 더 뻗는다 | 6칸 |
| 🎈 | 동시에 놓을 수 있는 풍선 +1 | 6개 |
| 👟 | 이동 속도 증가 | +4단계 |

> 물줄기가 지나간 자리의 아이템은 쓸려 나갑니다. 단, **그 상자를 부순 물줄기에는 안 쓸려 갑니다** —
> 부수자마자 사라지면 아이템을 영영 못 먹기 때문입니다.

**알아 두면 좋은 것**

- 자기 물풍선에도 갇힙니다. 놓고 나서 **물줄기 길이보다 멀리** 피하세요
- 물줄기가 다른 물풍선에 닿으면 그 풍선도 **연쇄로 함께 터집니다**
- 발밑에 놓은 풍선은 그 칸에서 빠져나갈 때까지만 통과할 수 있습니다
- 물줄기는 터진 뒤 0.7초간 남아 있습니다. 사라지기 전에 돌아가면 자기 물에 갇힙니다
- 풀려난 직후 1.6초는 무적이라 연달아 갇히지 않습니다
- 9명 이상이면 앞 8명만 참여하고 나머지는 관전합니다 (다음 판부터 참여)
- 도중에 나간 사람은 그 자리에서 빠지고, 한 명만 남으면 판이 끝납니다

**지연·부정행위 대응** — 이동·충돌·폭발·점수 판정은 **전부 서버**가 합니다.
클라이언트가 보내는 것은 방향키 상태와 "풍선 놓기" 요청뿐이고, 서버가 위치를 다시 계산합니다.
내 캐릭터만 화면에서 미리 움직여 보여 주고(예측), 서버 값이 오면 조용히 맞춰 당깁니다.

> 맵 규격과 물리 상수(`WB`)는 **서버에만** 있습니다.
> 난이도를 바꾸려면 `server.js` 의 `WB` 만 고치면 됩니다
> (`fuse` 퓨즈 · `trapMs` 물방울 시간 · `boxRate` 상자 밀도 · `itemRate` 아이템 확률 등).

### 라이어 게임 규칙

상단 `🕵 라이어` 버튼으로 전환합니다. **3명 이상**이어야 시작할 수 있습니다.

1. 주제를 고르고(랜덤 가능) `게임 시작` — 주제는 음식·동물·직업·장소·여행·사물·스포츠 7종
2. 참가자 중 **한 명이 무작위로 라이어**가 됩니다
   - 시민: 주제와 **제시어**를 봅니다
   - 라이어: **주제만** 보고 제시어는 모릅니다
3. 화면에 뜬 순서대로 **채팅으로 한 마디씩** 제시어를 설명합니다
4. `투표 시작`을 누르면 투표 단계로 넘어갑니다 (자기 자신은 못 고릅니다)
5. 전원이 투표하면 자동 개표
   - **라이어가 최다 득표** → 라이어에게 제시어를 맞힐 **최후의 기회**. 맞히면 라이어 승, 틀리면 시민 승
   - **다른 사람이 지목되거나 동점** → 라이어 승

#### 🤪 바보 라이어 모드

`게임 시작` 옆에서 **바보 라이어**를 고르면 규칙이 하나 바뀝니다.

- 라이어에게도 제시어가 주어지지만, **전혀 다른 주제의 엉뚱한 단어**입니다
  (예: 시민은 `양궁`(스포츠), 라이어는 `여권`(여행))
- 라이어는 **자기가 라이어인 줄 모릅니다.** 화면이 시민과 완전히 똑같아서, 본인은 정상적으로
  설명하고 있다고 믿습니다
- 그래서 채팅에도 주제를 알리지 않습니다 — 각자 자기 화면의 주제만 봅니다
- 지목당해 최후의 기회로 넘어가는 순간에야 "사실 당신이 라이어였습니다"라고 알려 줍니다
- 결과 화면에는 진짜 제시어와 라이어가 받았던 가짜 제시어가 함께 공개됩니다

#### 공통

- 제시어는 **라이어의 브라우저로 아예 전송되지 않습니다.** 개발자도구로도 볼 수 없습니다
- 게임 도중 들어온 사람은 관전자가 되고 제시어를 받지 않습니다. 다음 판부터 참여합니다
- 라이어가 도중에 나가면 판이 종료되고 제시어가 공개됩니다
- 정답 판정은 띄어쓰기와 대소문자를 무시합니다 (`냉 면` = `냉면`)

### 레이싱 규칙

상단 `🏎 레이싱` 버튼으로 전환합니다.

- 조작: `↑` 가속 / `↓` 브레이크·후진 / `←` `→` 조향 (`W A S D` 도 동일)
- 트랙과 바퀴 수를 고르고 `레이스 시작` → `3 · 2 · 1` 카운트다운 후 출발

**트랙 4종** (`트랙 랜덤`을 고르면 서버가 무작위로 뽑습니다)

| 트랙 | 특징 | 코너 최소반경 | 도로 반폭 |
|---|---|---|---|
| 기본 오벌 | 넓고 단순, 최고속 유지하기 쉬움 | 112px | 92 |
| 땅콩 코스 | 완만한 두 개의 큰 곡선 | 143px | 90 |
| 물결 서킷 | 세 번 굽이치는 중급 코스 | 106px | 86 |
| 클로버 코스 | 코너가 네 번, 가장 기술적 | 103px | 86 |

> 트랙을 새로 만들 때는 **코너 최소반경을 100px 이상**으로 잡으세요.
> 전속력(520px/s) 회전반경이 168px이라, 이보다 많이 조이면 계속 감속해야 해서 재미가 없습니다.
> `polarTrack(웨이포인트수, 기준반지름, 진폭, 굴곡수, 세로비율)` 로 정의합니다.

- 차 색상은 참여자 고유색을 그대로 씁니다. 내 차에는 흰 테두리가 붙습니다
- **잔디로 나가면 크게 느려집니다** (도로 최고 520 → 잔디 약 130)
- 체크포인트를 **순서대로** 통과해야 한 바퀴로 인정됩니다. 안쪽으로 질러가면 바퀴가 오르지 않습니다
- 차끼리 부딪히면 서로 밀려나며 속도가 줄어듭니다
- 완주하면 순위·기록이 확정되고, 전원 완주하거나 5분이 지나면 레이스가 끝납니다
- 도중 입장한 사람은 관전만 하고 다음 판부터 참여합니다

**지연 대응** — 내 차는 브라우저에서 즉시 움직이고(로컬 예측), 서버가 계산한 실제 위치로 조금씩 보정합니다.
그래서 인터넷을 통해 접속해도 조작이 밀리는 느낌이 거의 없습니다. 물리 계산과 순위 판정은 서버가 하므로
브라우저를 조작해 빠르게 달리는 식의 부정행위는 통하지 않습니다.

> `server.js` 의 `RC` 상수와 `public/index.html` 의 `RC` 상수는 **반드시 같아야 합니다.**
> 한쪽만 고치면 내 차가 서버 위치와 어긋나 덜컹거립니다.
> 반면 **트랙 좌표는 서버가 내려주므로** `server.js` 의 `TRACKS` 만 고치면 됩니다.
> (대역폭을 아끼려고 카운트다운 중과 신규 접속자에게만 보내고, 클라이언트는 받은 것을 계속 씁니다)

### 채팅 — @지목과 이미지

**@지목**

- 입력창에 `@` 를 치면 접속자 목록이 뜹니다. `↑` `↓` 로 고르고 `Enter` 또는 `Tab` 으로 완성
- `@전체` (또는 `@all`) 는 접속자 전원을 지목합니다
- 지목된 사람 화면에서는 그 메시지에 파란 띠가 붙고 이름이 강조됩니다
- 이름 비교는 **서버가** 하므로, 이름에 특수문자가 있어도 정확히 동작합니다

**이미지 전송** — 채팅창 위 버튼 3개

| 버튼 | 동작 |
|---|---|
| 📷 사진 | 이미지 파일을 골라 전송 |
| 🎨 그림판 캡처 | 지금 그림판 화면을 그대로 이미지로 전송 |
| 🖥 화면 캡처 | 창·탭·전체 화면 중 하나를 골라 캡처해 전송 (브라우저가 권한을 물어봅니다) |

- 입력창에 **Ctrl+V 로 붙여넣어도** 전송됩니다
- 보내기 전에 가로·세로 1000px 이하로 줄이고 JPEG로 변환합니다 (한 장 최대 500KB)
- 채팅의 이미지를 클릭하면 크게 보입니다
- 메모리 보호를 위해 **최근 12장(합계 2MB)까지만** 남고, 그보다 오래된 이미지는 본문만 남습니다
- 새로 접속한 사람에게 지난 이미지를 한 번에 보내야 하므로 일부러 낮게 잡았습니다

## 사내망에서 쓰기

같은 사무실 네트워크에 있는 사람에게 `http://<내 PC IP>:3000` 과 암호를 전달하면 됩니다.
접속이 안 되면 방화벽을 열어야 합니다 — 관리자 권한 PowerShell에서 한 번만 실행하면 됩니다.

```bash
New-NetFirewallRule -DisplayName "공유 그림판 3000" -Direction Inbound -Protocol TCP -LocalPort 3000 -Action Allow -Profile Private
```

`-Profile Private` 이므로 사내망·집 네트워크에서만 열리고 공용 와이파이에서는 열리지 않습니다.

## 외부 사람도 들어오게 하기 (Render 배포)

회사 PC를 인터넷에 노출하지 않고, 코드만 외부 서버에 올려서 운영하는 방식입니다.
**가입은 직접 하셔야 합니다.** 아래 순서대로 진행하면 됩니다.

### 1. GitHub에 올리기

`shared-paint` 폴더가 저장소의 **루트**가 되도록 올립니다.

```bash
cd "C:\Users\ksyou\OneDrive\바탕 화면\로드엽\shared-paint"
git init
git add .
git commit -m "공유 그림판"
git branch -M main
git remote add origin https://github.com/<내계정>/shared-paint.git
git push -u origin main
```

저장소는 **Private**으로 만드세요. 코드에 암호가 들어있진 않지만 공개할 이유도 없습니다.

### 2. Render에 연결

1. [render.com](https://render.com) 가입 (GitHub 계정으로 로그인 가능)
2. **New → Blueprint** 선택 → 방금 만든 저장소 연결
3. `render.yaml` 이 자동으로 읽히면서 설정이 잡힙니다
4. `ROOM_PASSWORD` 값을 입력하라고 나오면 **외부에 알려줄 암호**를 입력
5. Apply → 1~2분 뒤 `https://shared-paint-xxxx.onrender.com` 주소가 발급됩니다

이 주소와 암호를 외부 인원에게 전달하면 됩니다. HTTPS가 자동 적용되고,
회사 네트워크와는 완전히 분리되어 있습니다.

### 무료 플랜에서 알아둘 점

- **15분간 아무도 안 쓰면 서버가 잠듭니다.** 다시 접속하면 깨어나는 데 30초~1분 걸리고,
  그동안 그려둔 그림과 채팅은 **전부 사라집니다.**
- 회의 직전에 미리 한 번 열어서 깨워두고 쓰시는 걸 권합니다.
- 그림을 남겨야 한다면 PNG 저장 기능을 추가하는 편이 안전합니다.

## 알아두실 점

- **그림과 채팅은 저장되지 않습니다.** 서버 메모리에만 있어서 서버가 꺼지거나 재시작되면 전부 사라집니다.
- 그림이 아주 많이 쌓이면(획 8만 조각) 오래된 것부터 지워지고, 채팅은 최근 200개만 보관됩니다.
- 채팅 이미지는 **최근 12장(합계 2MB)까지만** 메모리에 남습니다. 남겨야 할 이미지는 따로 저장해 두세요.
- **전체 지우기는 누구나 누를 수 있고 되돌릴 수 없습니다.** 암호를 아는 사람끼리만 공유하세요.
- 실행취소는 **내 획만** 대상입니다. 연결이 한 번 끊겼다 다시 붙으면 그 이전에 그린 획은 취소할 수 없습니다.
- 암호는 방 하나를 여는 열쇠일 뿐이고 개인 계정이 아닙니다. 외부에 공유한 암호는 회의가 끝나면
  `ROOM_PASSWORD` 를 바꿔 재배포하는 것이 좋습니다.
