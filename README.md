# 공유 그림판

여러 명이 동시에 접속해서 하나의 캔버스에 함께 그리고, 채팅으로 대화하는 웹 그림판입니다.
외부 패키지 설치 없이 Node.js만 있으면 바로 실행됩니다.

## 실행

```bash
node "C:\Users\ksyou\OneDrive\바탕 화면\로드엽\shared-paint\server.js"
```

실행하면 콘솔에 접속 주소와 **접속 암호**가 표시됩니다.

```
  내 PC        : http://localhost:3000
  같은 네트워크 : http://10.20.0.106:3000
  접속 암호     : 903351   ← 이 암호를 함께 전달하세요
```

## 접속 암호

`ROOM_PASSWORD` 환경변수로 정합니다.

| 설정 | 동작 |
|---|---|
| 지정 안 함 | 6자리 숫자를 자동 생성해 콘솔에 표시 (서버를 다시 켜면 바뀜) |
| `ROOM_PASSWORD="원하는암호"` | 그 값이 접속 암호가 됨 |
| `ROOM_PASSWORD="off"` | 암호 없이 개방 — **사내망 전용으로만** |

암호를 고정해서 실행하려면 (PowerShell):

```bash
$env:ROOM_PASSWORD="tripto2026"; node "C:\Users\ksyou\OneDrive\바탕 화면\로드엽\shared-paint\server.js"
```

포트를 바꾸려면 `$env:PORT=8080` 을 같은 방식으로 지정하면 됩니다.
종료는 실행 중인 창에서 `Ctrl+C`.

암호를 한 번 입력하면 12시간 동안 유지되고, 서버를 다시 켜면 모두 다시 입력해야 합니다.
암호를 10분에 10번 틀리면 해당 IP는 잠시 차단됩니다.

## 기능

| 기능 | 설명 |
|---|---|
| 펜 | 색상 8종 팔레트 + 직접 색 선택, 굵기 1~60 |
| 붓 크기 표시 | 마우스를 따라다니는 원으로 현재 붓 굵기를 미리 보여줌 (지우개는 점선) |
| 지우개 | 굵기 조절 가능, 지운 것도 모두에게 실시간 반영 |
| 실행취소 | `↶ 실행취소` 버튼 또는 `Ctrl+Z`. **내가 그린 획만** 최신 순으로 취소되고, 남의 그림은 건드리지 않음 |
| 칸 나누기 | `⊞ 칸 나누기` — 참여자 수에 맞춰 캔버스를 격자로 나누고 각자 자기 칸에만 그리게 함. 누가 켜든 **모두에게 동시에 적용**됨 |
| 전체 지우기 | 확인창을 거쳐 모두의 캔버스를 초기화 (되돌릴 수 없음) |
| 참여자 표시 | 상단에 접속자 이름과 고유 색상 표시 |
| 커서 공유 | 다른 사람 마우스 위치가 이름표와 함께 실시간 표시 |
| 채팅 | 우측 패널, Enter 전송 / Shift+Enter 줄바꿈 |
| 이름 변경 | 상단 입력칸에서 변경, 브라우저에 저장되어 다음에도 유지 |
| 빙고 | 상단 `🎲 빙고`로 전환. 4×4 / 5×5 판, 목표 줄 수 선택 가능 (아래 참고) |
| 라이어 게임 | 상단 `🕵 라이어`로 전환. 3명 이상, 주제 7종, 투표·최후 기회 포함 (아래 참고) |
| 나중에 입장 | 그때까지 그려진 그림과 채팅 기록을 그대로 받아 봄 |
| 자동 재연결 | 연결이 끊기면 1.5초마다 재접속 시도 |

캔버스는 1600×900 기준으로 동작하며, 화면 크기가 달라도 모두 같은 그림을 봅니다.

### 칸 나누기 규칙

접속 순서대로 왼쪽 위부터 칸이 배정됩니다.

| 인원 | 격자 |
|---|---|
| 2명 | 좌우 2칸 |
| 3~4명 | 2×2 |
| 5~6명 | 3×2 |
| 7~9명 | 3×3 |

- 칸 경계를 넘어가면 선이 경계에서 멈춥니다 (칸 밖으로는 그려지지 않습니다)
- 사람이 들어오거나 나가면 칸이 다시 배정됩니다. **이미 그려둔 그림은 그 자리에 남습니다**
- 칸을 끄면 다시 캔버스 전체에 자유롭게 그릴 수 있습니다

### 빙고 규칙

상단 `🎲 빙고` 버튼으로 전환합니다. 그림판 내용은 그대로 남아 있어 언제든 오갈 수 있습니다.

1. 판 크기(**4×4** 또는 **5×5**)와 목표 줄 수를 고르고 `게임 시작`
2. 참여자마다 **서로 다르게 섞인 판**을 받습니다 (4×4는 1~16, 5×5는 1~25)
3. 접속 순서대로 돌아가며 자기 차례에 숫자를 하나 부릅니다
4. 부른 숫자는 **모두의 판에서 자동으로 체크**됩니다
5. 가로·세로·대각선으로 목표 줄 수를 먼저 채우면 승리 — 동시 달성이면 공동 우승

- 목표 줄 수는 판 크기에 맞춰 자동 조정됩니다 (4×4는 최대 10줄, 5×5는 최대 12줄)
- 누가 시작하면 **모두 자동으로 빙고 화면으로 전환**되고, 채팅에 진행 상황이 남습니다
- 게임 중에 들어온 사람도 판을 받아 순번 끝에 합류합니다
- 차례인 사람이 나가면 자동으로 다음 사람에게 넘어갑니다
- 자기 차례가 아니거나 게임이 끝난 뒤의 입력은 서버가 받지 않습니다

### 라이어 게임 규칙

상단 `🕵 라이어` 버튼으로 전환합니다. **3명 이상**이어야 시작할 수 있습니다.

1. 주제를 고르고(랜덤 가능) `게임 시작` — 주제는 음식·동물·직업·장소·여행·사물·스포츠 7종
2. 참가자 중 **한 명이 무작위로 라이어**가 됩니다
   - 시민: 주제와 **제시어**를 봅니다
   - 라이어: **주제만** 보고 제시어는 모릅니다
3. 화면에 뜬 순서대로 **채팅으로 한 마디씩** 제시어를 설명합니다
4. `투표 시작`을 누르면 투표 단계로 넘어갑니다 (자기 자신은 못 고릅니다)
5. 전원이 투표하면 자동 개표
   - **라이어가 최다 득표** → 라이어에게 제시어를 맞힐 **최후의 기회**. 맞히면 라이어 승, 틀리면 시민 승
   - **다른 사람이 지목되거나 동점** → 라이어 승

- 제시어는 **라이어의 브라우저로 아예 전송되지 않습니다.** 개발자도구로도 볼 수 없습니다
- 게임 도중 들어온 사람은 관전자가 되고 제시어를 받지 않습니다. 다음 판부터 참여합니다
- 라이어가 도중에 나가면 판이 종료되고 제시어가 공개됩니다
- 정답 판정은 띄어쓰기와 대소문자를 무시합니다 (`냉 면` = `냉면`)

## 사내망에서 쓰기

같은 사무실 네트워크에 있는 사람에게 `http://<내 PC IP>:3000` 과 암호를 전달하면 됩니다.
접속이 안 되면 방화벽을 열어야 합니다 — 관리자 권한 PowerShell에서 한 번만 실행하면 됩니다.

```bash
New-NetFirewallRule -DisplayName "공유 그림판 3000" -Direction Inbound -Protocol TCP -LocalPort 3000 -Action Allow -Profile Private
```

`-Profile Private` 이므로 사내망·집 네트워크에서만 열리고 공용 와이파이에서는 열리지 않습니다.

## 외부 사람도 들어오게 하기 (Render 배포)

회사 PC를 인터넷에 노출하지 않고, 코드만 외부 서버에 올려서 운영하는 방식입니다.
**가입은 직접 하셔야 합니다.** 아래 순서대로 진행하면 됩니다.

### 1. GitHub에 올리기

`shared-paint` 폴더가 저장소의 **루트**가 되도록 올립니다.

```bash
cd "C:\Users\ksyou\OneDrive\바탕 화면\로드엽\shared-paint"
git init
git add .
git commit -m "공유 그림판"
git branch -M main
git remote add origin https://github.com/<내계정>/shared-paint.git
git push -u origin main
```

저장소는 **Private**으로 만드세요. 코드에 암호가 들어있진 않지만 공개할 이유도 없습니다.

### 2. Render에 연결

1. [render.com](https://render.com) 가입 (GitHub 계정으로 로그인 가능)
2. **New → Blueprint** 선택 → 방금 만든 저장소 연결
3. `render.yaml` 이 자동으로 읽히면서 설정이 잡힙니다
4. `ROOM_PASSWORD` 값을 입력하라고 나오면 **외부에 알려줄 암호**를 입력
5. Apply → 1~2분 뒤 `https://shared-paint-xxxx.onrender.com` 주소가 발급됩니다

이 주소와 암호를 외부 인원에게 전달하면 됩니다. HTTPS가 자동 적용되고,
회사 네트워크와는 완전히 분리되어 있습니다.

### 무료 플랜에서 알아둘 점

- **15분간 아무도 안 쓰면 서버가 잠듭니다.** 다시 접속하면 깨어나는 데 30초~1분 걸리고,
  그동안 그려둔 그림과 채팅은 **전부 사라집니다.**
- 회의 직전에 미리 한 번 열어서 깨워두고 쓰시는 걸 권합니다.
- 그림을 남겨야 한다면 PNG 저장 기능을 추가하는 편이 안전합니다.

## 알아두실 점

- **그림과 채팅은 저장되지 않습니다.** 서버 메모리에만 있어서 서버가 꺼지거나 재시작되면 전부 사라집니다.
- 그림이 아주 많이 쌓이면(획 8만 조각) 오래된 것부터 지워지고, 채팅은 최근 200개만 보관됩니다.
- **전체 지우기는 누구나 누를 수 있고 되돌릴 수 없습니다.** 암호를 아는 사람끼리만 공유하세요.
- 실행취소는 **내 획만** 대상입니다. 연결이 한 번 끊겼다 다시 붙으면 그 이전에 그린 획은 취소할 수 없습니다.
- 암호는 방 하나를 여는 열쇠일 뿐이고 개인 계정이 아닙니다. 외부에 공유한 암호는 회의가 끝나면
  `ROOM_PASSWORD` 를 바꿔 재배포하는 것이 좋습니다.
